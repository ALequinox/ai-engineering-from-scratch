## 1. 信息量与熵

事件越罕见，发生时越令人意外。概率为 `p` 的事件的信息量是 `-log₂(p)` bits：概率为 `1` 时是 `0` bit，`1/2` 时是 `1` bit，`1/8` 时是 `3` bits。熵是按各结果发生概率加权的平均信息量：

```text
H(P) = Σ p(x) × [-log₂ p(x)]
P = [1/2, 1/4, 1/4]
H(P) = (1/2)×1 + (1/4)×2 + (1/4)×2 = 1.5 bits
```

课堂第一次只算出首项 `0.5`，补上另两项后算出 `1.5`。确定事件的熵为零；仓库程序输出公平硬币 `1.0000` bits，99%/1% 偏置硬币 `0.0808` bits。

## 2. 交叉熵、KL 散度与最大似然

交叉熵 `H(P,Q) = -Σ p(x)log q(x)` 衡量真实事件来自 `P`、而模型用 `Q` 预测时的平均意外程度。若真实标签是 one-hot，单个样本的分类损失简化为 `-log q(真实类别)`；模型给真实类别的概率越小，损失越大。课堂用以 2 为底的对数算出：给正确类别 `1/2` 的损失是 `1` bit，给 `1/4` 的损失是 `2` bits。

```text
H(P,Q) = H(P) + D_KL(P‖Q)
D_KL(P‖Q) = H(P,Q) − H(P)
```

真实分布固定时，`H(P)` 是常数。交叉熵从 `1.3` 降到 `1.1` bits 且 `H(P)=1` bit 时，KL 从 `0.3` 降到 `0.1` bit。课堂初次把方向判断为“上升”，代入数值后订正。若 `P=Q=[0.5,0.5]`，交叉熵为 `1` bit，而 KL 是 `0` bit；课堂初次误答 KL 为 `1`，已纠正。KL 衡量额外信息代价，且通常不对称。

对多个训练样本，真实标签的预测概率相乘得到似然；取对数变成求和，取负号并平均即分类交叉熵。因而最小化交叉熵等价于最大化这些训练标签的对数似然。实际机器学习库通常用自然对数，单位为 nats；`1 bit ≈ 0.6931 nats`。

## 3. 困惑度与互信息

困惑度是平均交叉熵的指数：若损失以 bits 计，用 `2 ** H`；若以 nats 计，用 `exp(H)`。`3` bits 对应困惑度 `8`，可理解为平均相当于从 8 个等概率候选 token 中选择。这个解释描述平均不确定性，并不表示模型每一步恰好列出 8 个词。

互信息 `I(X;Y)=H(Y)−H(Y|X)` 衡量观察特征 `X` 后，标签 `Y` 的不确定性减少多少。若 `H(Y)=1` bit、`H(Y|X)=0.2` bit，则互信息为 `0.8` bit。独立变量的互信息为零；互信息可捕捉线性和非线性依赖，而 Pearson 相关系数衡量线性关系。联合熵 `H(X,Y)` 表示两变量合在一起的不确定性，条件熵 `H(Y|X)` 表示观察 `X` 后的剩余不确定性。标签平滑把完全确定的 one-hot 标签变成软标签，可限制过度自信。
