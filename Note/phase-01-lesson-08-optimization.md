## 1. 梯度下降与学习率

训练时，损失函数衡量预测误差，梯度给出损失上升的方向。优化器沿相反方向更新权重：

```text
新权重 = 旧权重 − 学习率 × 梯度
```

用 `L(w)=w²`、初始 `w=2` 演算，梯度为 `2w=4`，初始损失为 4：

```text
学习率 0.5：w_new = 2 − 0.5×4 = 0；L(0) = 0
学习率 0.1：w_new = 2 − 0.1×4 = 1.6；L(1.6) = 2.56
学习率 1：w_new = 2 − 1×4 = −2；L(−2) = 4
```

学习率为 1 时，下一步又回到 `w=2`，形成来回震荡。课堂先把题设学习率 1 代成了 0.1；计算 `w=1.6` 本身正确，但对应另一种设置，已订正。

全批次每次用全部训练数据计算梯度；单样本 SGD 每次用一条；小批次用一组。1,000 条样本、每批 100 条时，一轮约更新 `1000/100=10` 次。小批次的随机波动有时有助于离开平坦区或浅局部低点，但不能保证一定改善训练。

## 2. 手写优化器与逐步计算

仓库的 Rosenbrock 测试函数为 `f(x,y)=(1−x)²+100(y−x²)²`，最低点在 `(1,1)`。从 `(-1,1)` 出发，初始损失为 4，梯度为 `[-4,0]`。普通梯度下降用学习率 `0.0005` 更新一步：

```text
x_new = −1 − 0.0005×(−4) = −0.998
y_new = 1 − 0.0005×0 = 1
新损失 = 3.9936008016
```

动量法把过去的梯度累积为速度：`v_new=βv_old+g`。若 `β=0.9`、初始速度 0、连续两步梯度均为 2，则第一步速度为 2，第二步为 `0.9×2+2=3.8`。同向梯度推动速度累积，交替方向的梯度则会相互抵消一部分。

Adam 每个权重保存梯度的一阶移动平均 `m` 和梯度平方的二阶移动平均 `v`，并对零初始化做偏差修正。第一步若梯度为 2、`β₁=0.9`、`β₂=0.999`：

```text
m = 0.9×0 + 0.1×2 = 0.2
v = 0.999×0 + 0.001×2² = 0.004
m_hat = 0.2/(1−0.9) = 2
v_hat = 0.004/(1−0.999) = 4
更新量 = lr × m_hat/(sqrt(v_hat)+epsilon)
```

`lr/sqrt(v_hat)` 可视为按梯度幅度缩放的系数。梯度较大时这个系数较小，但 `m_hat` 也会变化，不能单凭梯度大小断言最终权重更新量更小。课堂中导师先用了过简化的说法，随后澄清了系数与实际更新量的区别。

## 3. 学习率计划与鞍点

余弦退火把学习率从较高值平滑降到较低值；若起点为 `0.1`、终点为 `0.01`，在预定步数的一半处为 `(0.1+0.01)/2=0.055`。预热阶段可以先从较小学习率逐渐升高，再进入衰减。

`L(x,y)=x²−y²` 在原点的梯度为零，但 `L(0,y)=−y²<0`（当 `y≠0`），因此原点是鞍点，不是最低点。课堂正确判断“梯度为零不能断定找到最低点”。凸函数与非凸函数的区别、优化器能否离开鞍点，都要结合起点和函数形状判断；从恰好为零梯度的位置出发，确定性的梯度更新不会自行移动。
