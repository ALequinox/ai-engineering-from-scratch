## 1. 导数是局部变化率

导数 `f′(x)` 描述 x 附近输入发生很小变化时，函数输出如何变化。几何上，它是切线斜率。

```text
f(x)=x²
x 从 2 到 2.1：输入变化 0.1，输出从 4 到 4.41，变化 0.41
平均变化率 = 0.41 / 0.1 = 4.1
x 从 2 到 2.01：平均变化率 4.01
x 从 2 到 2.001：平均变化率 4.001
在 x=2 的导数是 4，且 f′(x)=2x
```

导数给出局部近似：在 x=2 附近，输出变化量约等于 `4×输入变化量`。例如 x 增加 0.001，输出约增加 0.004；实际增量是 0.004001。

导数为负时，沿 x 增大的方向函数值下降。例如 `x=-2` 时，`f′(x)=-4`；调大 x 到 −1.9 后，平方值从 4 降到 3.61。注意 x 增大不意味着 x² 也增大。

## 2. 中央差分近似导数

对于不容易手算求导的函数，可以在 x 两侧取点，用中央差分估算：

```text
f′(x) ≈ [f(x+h)−f(x−h)] / (2h)
```

`h` 是小步长。相比单侧差分，两侧对称取点通常能给出更好的局部估计，但浮点舍入和 h 的选择也会影响结果。

```python
def numerical_derivative(f, x, h=1e-7):
    return (f(x + h) - f(x - h)) / (2 * h)

print(numerical_derivative(lambda x: x**2, 2.0))
```

课堂实际运行输出为 `3.9999999957`，解析导数是 `4.0000000000`。

## 3. 梯度下降

梯度下降沿负梯度方向更新参数：

```text
新参数 = 旧参数 − 学习率 × 当前梯度
```

学习率控制步长；每次更新后要在新位置重新计算梯度。

```text
f(x)=x²，f′(x)=2x，从 x=2 出发：
学习率 0.1：2 → 1.6 → 1.28，损失 4 → 2.56 → 1.6384
学习率 1.1：2 → −2.4，损失 4 → 5.76，步子太大越过低点
学习率 0.5：2 → 0，损失 4 → 0
```

学习率 0.5 这次恰好到达最低点，是这个特定函数和起点的结果，不是通用保证。过大可能震荡或发散，过小则收敛慢。

本课小循环：

```python
x = 5.0
lr = 0.1
for step in range(3):
    grad = 2 * x
    x = x - lr * grad
    print(step + 1, x, x ** 2)
```

学习者正确预测第一次更新是 x=4、损失 16；该三步代码片段没有单独运行。

## 4. 多变量偏导与梯度

偏导数一次只改变一个变量，其他变量保持不动。例子：

```text
f(x,y)=x²+3xy+y²
∂f/∂x=2x+3y
∂f/∂y=3x+2y
在 (1,2)：梯度 ∇f=[8,7]
```

梯度收集所有偏导数，指向函数上升最快的方向。要降低函数值，就沿相反方向走。

在学习率 0.1 下从 `(1,2)` 更新：

```text
(x,y) − 0.1×[8,7] = (0.2,1.3)
f(1,2)=11
f(0.2,1.3)=2.51
```

课堂数值梯度代码的逐坐标做法：复制点，只改当前坐标的正负 h，其余坐标固定，再计算中央差分并收集结果。对上述 f 在 `[1,2]` 实际运行得到 `[8.0,7.0]`，与解析梯度 `[8,7]` 一致。

## 5. 链式法则与反向传播

函数由多步组合时，整体导数等于沿路径的局部导数相乘：

```text
y=(3x+1)²
内层 u=3x+1，du/dx=3
外层 y=u²，dy/du=2u
dy/dx=2(3x+1)×3
x=1 时导数为 24
```

神经网络把线性变换、激活函数、损失函数接成计算链。反向传播就是从损失往回应用链式法则，求每个参数对损失的导数。

单个线性预测的平方误差示例：

```text
pred = w*x+b
error = pred−y
L = error²
∂L/∂w = 2×error×x
∂L/∂b = 2×error
```

当 `x=2,y=5,w=1,b=0` 时，预测 2、误差 −3，故 `∂L/∂w=−12`、`∂L/∂b=−6`。学习率 0.1 更新后 `w=2.2,b=0.6`，恰好预测 5。一个样本拟合正确不表示模型已能泛化。

## 6. 多样本平均损失与梯度

对批次样本，先累计每个样本对损失及参数梯度的贡献，再除以样本数。平均梯度是批次平均损失的梯度，也避免更新幅度直接随批次大小放大；它不保证每一步都更准确，也不保证每一步损失下降。

课堂例子：两个样本的 w 梯度为 −12 和 −4，平均为 −8。

两个样本 `(x,y)=([1,2],[3,5])`，初始 `w=b=0`：

```text
dw = [2×(−3)×1 + 2×(−5)×2] / 2 = −13
db = [2×(−3) + 2×(−5)] / 2 = −8
lr=0.1 后：w=1.3，b=0.8
```

导师实际运行该更新：平均损失从 17 降到 1.685，更新后预测是 `[2.1,3.4]`。两个参数必须在同一批次梯度计算完之后再更新。

## 7. 线性回归训练实跑

课程示例使用 `xs=[1,2,3,4,5]`、`ys=[3,5,7,9,11]`，目标直线为 `y=2x+1`。每轮先计算预测、平方误差和 `w,b` 的梯度均值，再更新参数。

导师以固定随机种子实际运行 200 轮：

```text
epoch   0：w=0.3980，b=−0.0208，loss=67.032927
epoch  40：w=2.1296，b=0.5319，loss=0.040145
epoch  80：w=2.1132，b=0.5912，loss=0.030618
epoch 120：w=2.0989，b=0.6430，loss=0.023351
epoch 160：w=2.0863，b=0.6883，loss=0.017809
epoch 199：w=2.0757，b=0.7268，loss=0.013675
最终参数约为 w=2.08、b=0.73，逐渐接近目标 2 和 1。
```

源码在每轮更新参数前记录 loss，因此最后一行的损失对应最后一次更新前的参数。随机初始化不同会改变过程；固定种子便于复现。

## 8. sigmoid 与交叉熵的链式法则

sigmoid 把实数映射到 0 到 1：`σ(z)=1/(1+e^(−z))`。若输出为 a，其导数为 `a(1−a)`；当 a=0.5 时导数为 0.25。

二分类交叉熵中，标签 y=1、预测 a=0.5 时：

```text
∂L/∂a = −y/a + (1−y)/(1−a) = −2
∂a/∂z = a(1−a) = 0.25
∂L/∂z = (∂L/∂a)(∂a/∂z) = −0.5
```

对 sigmoid 与二元交叉熵，这两个导数相乘可化简为 `a−y`。负梯度表示增加 z 会降低该例的损失。

## 9. 海森矩阵、极值与牛顿法

海森矩阵由二阶偏导数组成，描述曲率。只在梯度为零的临界点附近，用正定性判断局部极小值、负定性判断局部极大值、正负特征值混合判断鞍点；半正定或零特征值时，单看二阶信息可能不能定论。

```text
f=x²−y² 的原点：H=[[2,0],[0,−2]]，特征值一正一负，是鞍点。
f=x²+y² 的原点：H=[[2,0],[0,2]]，两者为正，是局部极小值。
```

学习者起初将混合正负判断为局部最小值，后通过“一方向谷底、另一方向山顶”的提示订正为鞍点；之后正确回答全负意味着向下弯。适合间隔复习。

一维牛顿法更新：`x_new=x−f′(x)/f″(x)`，它使用斜率与曲率。`f=x²` 在 x=2 时一步到 0；梯度下降用 lr=0.1 时到 1.6。

完整 N×N 海森矩阵需 O(N²) 存储，标准直接求解/求逆约 O(N³) 计算，难以应用到百万参数模型。实际方法会使用近似、结构或一阶优化器；不能把 Adam 简化为完整海森矩阵的对角近似。

## 10. 泰勒近似与积分

在点 x 附近，泰勒展开用导数近似函数：

```text
f(x+h) ≈ f(x) + f′(x)h + (1/2)f″(x)h² + …
```

只保留一阶项是局部线性近似，与梯度下降的直觉相连；加入二阶项可描述曲率，与牛顿法相连。例：`sin(0.5)≈0.5`，真实值约 0.4794；距离展开点越远，近似可能变差。

积分可理解为连续累积或曲线下面积。连续概率密度的区间概率、期望损失、KL 散度和贝叶斯归一化常数都涉及积分。训练数据的平均损失是总体期望损失的经验近似。
