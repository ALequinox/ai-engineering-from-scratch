## 1. 向量：按固定顺序排列的数字

向量由若干分量组成，分量的数量就是维度。

例如，约定电影偏好的顺序为「动作、喜剧、科幻」，那么 `[2, 4, 5]` 是三维向量，第二个分量 4 表示对喜剧片的喜爱程度。顺序改变，含义也会改变。

向量也可以表示位置或方向：`[3, 2]` 可以表示从原点向右 3、向上 2。这里的二维对应平面的两个坐标。

AI 中的嵌入（embedding）用向量表示文本等对象。真实嵌入的各个分量通常没有「动作偏好」这样直接可解释的含义。

## 2. 向量加法：对应分量相加

在分量数量和含义一致时，可以用加法累计数据。例如三天的电影观看次数：

```text
第一天：[1, 2, 0]
第二天：[2, 1, 1]
第三天：[0, 1, 2]
前两天：[1+2, 2+1, 0+1] = [3, 3, 1]
三天合计：[3, 3, 1] + [0, 1, 2] = [3, 4, 3]
```

向量加法的结果仍然是向量。

## 3. 点积：对应相乘，再求和

点积的结果是一个数（标量）：

```text
a·b = a₁b₁ + a₂b₂ + … + aₙbₙ
[2, 4, 5]·[1, 1, 0] = 2×1 + 4×1 + 5×0 = 6
```

在课堂的简化推荐系统中，用偏好 `[2, 4, 5]` 给电影评分：

- 电影 `[0, 1, 1]`：得分 9。
- 电影 `[1, 1, 0]`：得分 6。
- 电影 `[0, 0, 1]`：得分 5。

点积同时受长度和方向影响，不能一概当成纯粹的语义相似程度。对非零向量，点积为正表示夹角小于 90°，为零表示正交，为负表示夹角大于 90°；正、负不一定表示完全同向或完全反向。

## 4. 矩阵与矩阵乘向量

矩阵是按行、列排列的数字，形状写成「行数 × 列数」。把电影特征放在每一行，就得到一个矩阵。

```text
M 的两行是 [0, 1, 1] 和 [1, 1, 0]，形状为 2×3。
输入向量 x = [2, 4, 5]。
每一行分别与 x 做点积，得到 Mx = [9, 6]。
增加第三行 [0, 0, 1] 后，输出变为 [9, 6, 5]。
```

一般来说，m×n 矩阵乘 n 维向量，输出 m 维向量。

矩阵也能表示线性变换。例如：

```text
矩阵的行：[2, 0]、[0, 1]
输入：[3, 2]
输出：[2×3 + 0×2, 0×3 + 1×2] = [6, 2]
作用：横坐标扩大为原来的 2 倍。

矩阵的行：[1, 0]、[0, 3]
输入：[3, 2]
输出：[3, 6]
作用：纵坐标扩大为原来的 3 倍。
```

神经网络的线性层使用矩阵乘法，通常还加上偏置；完整网络还包含非线性运算。

## 5. 长度、归一化与余弦相似度

向量的长度（模）是各分量平方之和的平方根：

```text
‖[3, 4]‖ = √(3² + 4²) = √25 = 5
‖[6, 8]‖ = 10
```

将所有分量乘以同一个正数，方向不变，长度按同样比例变化。

归一化是把每个分量除以向量长度，得到方向不变、长度为 1 的单位向量：

```text
[3, 4] ÷ 5 = [0.6, 0.8]
[6, 8] ÷ 10 = [0.6, 0.8]
```

零向量不能用这个方法归一化，因为不能除以 0。

余弦相似度等于两个向量归一化后的点积：

```text
cosine(a, b) = (a·b) / (‖a‖ × ‖b‖)
[3, 4] 与 [6, 8]：0.6×0.6 + 0.8×0.8 = 1
[1, 0] 与 [0, 1]：1×0 + 0×1 = 0
```

对于非零向量，1 表示同向，0 表示正交，−1 表示反向。文本检索可用它排序，但分数的语义价值依赖嵌入模型，不能把正交直接理解成文本完全无关。

## 6. 投影：保留指定方向上的部分

把 a 投影到非零向量 b 的方向上：

```text
proj_b(a) = (a·b / b·b) × b
```

直观例子：`[3, 4]` 投影到水平轴得到 `[3, 0]`，投影到竖直轴得到 `[0, 4]`。

斜方向的课堂练习：

```text
a = [2, 4]，b = [1, 1]
a·b = 2×1 + 4×1 = 6
b·b = 1×1 + 1×1 = 2
倍数 = 6÷2 = 3
投影 = 3×[1, 1] = [3, 3]
剩余部分 = [2, 4] − [3, 3] = [−1, 1]
剩余部分与 b 的点积 = −1×1 + 1×1 = 0
```

原向量 = 投影 + 剩余部分；剩余部分与投影方向正交。

## 7. 线性组合、线性无关、基与秩

线性组合是把向量分别乘以系数，再相加：

```text
2×[1, 0] + 3×[0, 1] = [2, 3]
```

如果一组向量中有一个能由其他向量线性组合得到，这组向量就线性相关。例如 `[2, 0]` 是 `[1, 0]` 的 2 倍，没有增加新的独立方向；它们也无法组合出 `[0, 1]`。

基是一组线性无关、且能组合出目标空间中任意向量的向量。`[1, 0]` 与 `[0, 1]` 是二维平面的一组基。

矩阵的秩等于线性无关列的最大数量，也等于线性无关行的最大数量：

- 以 `[1, 0]`、`[0, 1]`、`[2, 3]` 为列：第三列是前两列的组合，秩为 2。
- 以 `[1, 0]`、`[2, 0]`、`[3, 0]` 为列：只有一个独立方向，秩为 1。
- 把 `[3, 0]` 换成 `[-3, 0]` 也不增加独立方向，秩仍为 1。

特征列线性相关表示存在冗余。在无约束线性最小二乘中，列秩不足会导致权重解不唯一。满列秩也不保证数值稳定，还需要考虑条件数。

## 8. Gram–Schmidt 正交化

目的：将线性无关的向量变成互相正交、长度为 1 的向量，同时保留它们张成的空间。

步骤：先把第一个向量归一化；之后对每个向量，减去它在已有正交方向上的投影，再归一化。

课堂例子：

```text
a = [1, 0]，b = [1, 1]
a 已经是单位向量。
b 在 a 上的投影是 [1, 0]。
b − 投影 = [0, 1]，长度恰好也是 1。
得到标准正交基：[1, 0]、[0, 1]。
```

如果减去投影后剩余长度不是 1，还需要归一化。如果剩余为零，说明该向量没有增加新的独立方向，不能直接除以其长度。

## 9. Python 手写实现与实际输出

下面的简化代码假设向量维度相同，且投影方向 b 非零。正式实现还需要检查输入；`zip` 遇到长度不同的序列会在较短序列结束时停止。

```python
def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

def project(a, b):
    scale = dot(a, b) / dot(b, b)
    return [scale * value for value in b]

print(project([2, 4], [1, 1]))
```

导师在课堂中实际运行的结果：

```text
[3.0, 3.0]
```

Python 的 `/` 返回浮点数，因此这里以小数形式显示。课堂还实际运行了点积累计循环：

```python
preferences = [2, 4, 5]
movie = [1, 1, 0]
score = 0
for preference, feature in zip(preferences, movie):
    score = score + preference * feature
    print(score)
```

每轮累计值依次是 2、6、6。`=` 表示赋值，右边计算出的新值会存回 `score`。

## 10. NumPy 版本与容易混淆的地方

```python
import numpy as np

a = np.array([2, 4], dtype=float)
b = np.array([1, 1], dtype=float)
scale = np.dot(a, b) / np.dot(b, b)
projection = scale * b
print(projection)
```

`np.dot` 代替手写的对应相乘与求和，`scale * b` 代替逐个分量相乘。公式不变，循环交给库实现。

普通 Python 列表与 NumPy 数组的乘法含义不同：

```python
[1, 1] * 3                 # 重复列表：[1, 1, 1, 1, 1, 1]
np.array([1, 1]) * 3        # 分量乘法：array([3, 3])
2 * np.array([2, 5])        # array([4, 10])
```

## 11. LoRA：只训练低秩权重更新

LoRA 冻结基础权重，用两个较小的可训练矩阵相乘，表示权重更新。

课堂例子：原权重形状为 `100×100`，包含 10,000 个参数。改为训练 `100×2` 与 `2×100` 两个矩阵，共 `200+200=400` 个额外参数。它们相乘后仍得到 `100×100` 的更新矩阵，但秩最多为 2。

这 400 个参数是微调时额外训练的参数，不是整个模型的参数总量。减少参数的代价是限制了更新可表达的变化。
