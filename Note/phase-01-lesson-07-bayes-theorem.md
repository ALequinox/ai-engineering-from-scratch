## 1. 基准率与贝叶斯更新

先验 `P(A)` 是看到证据前对事件 A 的判断；似然 `P(B|A)` 是 A 成立时观察到 B 的概率；后验 `P(A|B)` 是看到 B 后更新的判断。证据概率 `P(B)` 把所有可能来源的 B 汇总，用于归一化。

```text
P(A|B) = P(B|A) × P(A) / P(B)
P(B) = P(B|A) × P(A) + P(B|非 A) × P(非 A)
```

疾病例子：每 10,000 人中 1 人患病，检测能检出 99% 的患者，健康人的误报率为 1%。逐步计算：

```text
P(患病) = 0.0001；P(健康) = 0.9999
P(阳性且患病) = 0.99 × 0.0001 = 0.000099
P(阳性且健康) = 0.01 × 0.9999 = 0.009999
P(阳性) = 0.000099 + 0.009999 = 0.010098
P(患病|阳性) = 0.000099 / 0.010098 ≈ 0.009804 = 0.98%
```

用人数近似理解：10,000 人中，约 1 位患者测出阳性，约 100 位健康人误报阳性，因此阳性者中约 `1/101` 患病。人数取整会得到约 0.99%，精确概率为 0.98%。课堂初次把健康人数 9,999 乘以 0.99；那是健康人测出阴性的概率。误报阳性要乘 0.01，已订正。

## 2. 垃圾邮件的后验概率

先验垃圾邮件比例 30%。`lottery` 出现在 5% 的垃圾邮件、0.1% 的正常邮件中。按 10,000 封邮件计算，3,000 封垃圾邮件中有 150 封含该词，7,000 封正常邮件中有 7 封含该词。因此：

```text
P(垃圾邮件|lottery) = 150 / (150 + 7) ≈ 95.5%
```

课堂先判断见到 `lottery` 会使垃圾邮件概率下降；因为该词在垃圾邮件中的出现率是正常邮件的 50 倍，更新方向应上升，已订正。随后算出约 95%。

## 3. 朴素贝叶斯分类器

朴素贝叶斯把多个词当作给定类别后的条件独立线索。训练阶段按类别记录邮件数、词频和词表。仓库实现对每个词逐个计数，因此 `free free money` 会让 `spam` 下的 `free` 计数增加 2。

未经平滑时，某类从未见过的词概率为 0，连乘后的类别分数也变为 0。默认拉普拉斯平滑给每个词加 1：

```text
P(词|类别) = (该类词频 + 1) / (该类总词数 + 词表大小)
```

例：该类总词数 10、词表大小 5，未见过的词概率是 `1/15`。预测阶段先计算类别先验，再累计每个词的对数似然：

```python
score = self._log_prior(cls)
for word in words:
    score += self._log_likelihood(word, cls)
```

对数把小概率连乘变为加法，防止数值下溢。分数较大的类别胜出；例如 `−6` 大于 `−9`。课堂正确算出 `−1−2−3=−6`，并选出 `spam`。

## 4. MLE、MAP 与顺序更新

MLE 只按观察数据估计参数：10 次抛硬币出现 7 次正面，估计正面概率为 0.70。MAP 还考虑参数先验；仓库示例中，`Beta(2,2)` 先验给出 MAP 估计 0.667，较强的 `Beta(10,10)` 先验给出 0.571。数据不断增加时，先验相对影响变小。高斯权重先验与 L2 正则化对应，但具体对应关系依赖损失与先验的尺度选择。

Beta 分布可表示对二项结果概率的信念。`Beta(a,b)` 看到 `s` 次成功、`f` 次失败后更新为 `Beta(a+s,b+f)`：

```text
Beta(1,1) + 7 次正面、3 次反面 = Beta(8,4)，均值 8/12 ≈ 0.667
Beta(8,4) + 5 次正面、5 次反面 = Beta(13,9)，均值 13/22 ≈ 0.591
```

第二批数据把均值拉回 0.5 附近。课堂独立答出 `Beta(13,9)`。这种更新也可用于对点击率等二项事件的顺序估计。
