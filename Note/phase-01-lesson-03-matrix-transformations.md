## 1. 矩阵的列表示基础向量的去向

二维线性变换由 `[1,0]`、`[0,1]` 的变换结果确定，分别放在矩阵的第一列、第二列。其他向量是这些基础向量的线性组合，变换保留组合关系。

```text
S = [[2,0], [0,1]]
[1,0] → [2,0]
[0,1] → [0,1]
[3,2] → [6,2]
```

## 2. 旋转、反射、缩放与剪切

逆时针旋转 90°：

```text
R = [[0,-1], [1,0]]
[x,y] → [-y,x]
[3,2] → [-2,3]
[2,1] → [-1,2]
```

记忆顺序：向右 → 向上 → 向左 → 向下 → 向右。课堂曾把逆时针转向上误写成向下，随后通过 `[0,1] → [-1,0]` 巩固。

反射：关于哪条坐标轴反射，就保留该坐标，改变另一坐标的符号。

```text
关于 x 轴：[[1,0], [0,-1]]， [x,y] → [x,-y]
关于 y 轴：[[-1,0], [0,1]]， [x,y] → [-x,y]
[3,4] 关于 x 轴反射 → [3,-4]
```

课堂曾混淆旋转与反射，以及反射轴与变号坐标，已通过练习纠正。

缩放与水平剪切：

```text
缩放 S = [[sx,0], [0,sy]]： [x,y] → [sx*x, sy*y]
剪切 H = [[1,1], [0,1]]： [x,y] → [x+y,y]
[2,3] 经 H → [5,3]
```

剪切可将正方形变为平行四边形。

## 3. 组合顺序

对列向量，先执行的变换写在靠近输入的位置：先 H 再 R，写作 `R @ H @ v`。

```text
R：逆时针旋转 90°
S：横坐标乘 2，纵坐标乘 0.5

先 R 再 S：[1,0] → [0,1] → [0,0.5]
先 S 再 R：[1,0] → [2,0] → [0,2]
```

矩阵乘法一般不满足交换律，但某些特殊矩阵可以交换；并非每次交换都会改变结果。

## 4. 三维旋转

绕 z 轴转 90°，x、y 旋转，z 保持不变。正角度从 z 轴正方向朝原点看是逆时针。

```text
Rz = [[0,-1,0], [1,0,0], [0,0,1]]
[x,y,z] → [-y,x,z]
[2,1,5] → [-1,2,5]
```

## 5. 行列式与复习题

二维情况下，行列式的绝对值是面积缩放倍数；负号表示朝向翻转。

```text
det([[2,0],[0,3]]) = 6：面积扩大 6 倍。
det([[2,0],[0,0]]) = 0：压掉一个维度，不可逆。
det([[1,1],[0,1]]) = 1：剪切保持面积，但不是单位变换。
```

行列式为 1 不代表单位矩阵，也不保证长度、角度保持不变。本课已正确回答“行列式 0、不可逆”，并正确否定“行列式 1 一定是单位矩阵”，上课错题获得一次复习验证。

## 6. 特征向量与特征值

非零向量 v 满足 `A @ v = λv` 时，v 是特征向量，λ 是对应特征值。结果是原向量乘以同一个数。

- λ 为正：保留朝向并缩放。
- λ 为负：反向并缩放，仍在同一直线上。
- λ 为零：非零向量被映射到零；零向量本身不能作为特征向量。

```text
S = [[2,0],[0,1]]
S @ [3,0] = [6,0] = 2×[3,0]：特征值 2。
S @ [1,1] = [2,1]：没有统一倍数，所以 [1,1] 不是 S 的特征向量。

F = [[-1,0],[0,1]]
F @ [1,0] = -1×[1,0]
F @ [0,2] = 1×[0,2]
```

本课主要矩阵：

```text
A = [[2,1],[1,2]]
A @ [1,1] = [3,3] = 3×[1,1]
A @ [1,-1] = [1,-1] = 1×[1,-1]
```

特征向量可乘以任意非零倍数，不一定是单位向量。

## 7. 特征方程：怎样求特征值

从 `Av = λv` 得到 `(A−λI)v = 0`。要存在非零解，`A−λI` 必须不可逆，因此 `det(A−λI)=0`。

```text
A = [[2,1],[1,2]]
A−λI = [[2−λ,1],[1,2−λ]]
(2−λ)²−1 = 0
(2−λ)² = 1
2−λ = 1 或 −1
λ = 1 或 3
```

求对应向量：λ=3 时，`2x+y=3x` 得到 y=x，可取 `[1,1]`；λ=1 时，`2x+y=x` 得到 y=−x，可取 `[1,-1]`。

一般二维矩阵的特征方程是 `λ²−(a+d)λ+(ad−bc)=0`。`a+d` 是迹，`ad−bc` 是行列式。

## 8. 手写代码与实际运行

以下为课堂使用的简化版本，仅在判别式非负时按实数求根；未加入输入验证和复数分支。

```python
def eigenvalues_2x2(matrix):
    a, b = matrix[0]
    c, d = matrix[1]
    trace = a + d
    det = a * d - b * c
    discriminant = trace ** 2 - 4 * det
    root = discriminant ** 0.5
    return ((trace + root) / 2, (trace - root) / 2)
```

导师实际运行 `[[2,1],[1,2]]`，得到 `(3.0,1.0)`，并验证：

```text
λ=3, v=[1,1]: A@v=[3,3], λv=[3,3]
λ=1, v=[1,-1]: A@v=[1,-1], λv=[1,-1]
```

课堂阅读、预测但未实际运行的变换函数：

```python
def rotation_90():
    return [[0, -1], [1, 0]]

def scaling_2d(sx, sy):
    return [[sx, 0], [0, sy]]

def mat_vec_mul(matrix, vector):
    result = []
    for row in matrix:
        value = sum(a * b for a, b in zip(row, vector))
        result.append(value)
    return result
```

此实现假设每行长度与向量维度相同；zip 不会自动报告长度不匹配。

## 9. 特征分解

当 n×n 矩阵具有 n 个线性无关特征向量时，可写成 `A = V @ D @ V⁻¹`。

- V 的列是特征向量。
- D 的主对角线是相应特征值。
- V⁻¹ 把输入换到特征向量构成的坐标系。

```text
V = [[1,1],[1,-1]]
D = [[3,0],[0,1]]
V⁻¹ = [[0.5,0.5],[0.5,-0.5]]
x = [2,0]

V⁻¹ @ x = [1,1]        换坐标
D @ [1,1] = [3,1]      分别缩放
V @ [3,1] = [4,2]      换回原坐标
```

导师实际运行这三个步骤，与直接计算 `A @ [2,0]` 的 `[4,2]` 一致。这里一般是换基，不应一概称为旋转。

课堂曾在向量相加时遗漏分量或负号。应先算缩放再按位置相加：`3×[1,1]+[1,-1]=[3+1,3−1]=[4,2]`。随后 `[4,4]+[2,-2]=[6,2]` 与最终换基计算均回答正确。

## 10. 应用：线性递推与 PCA

反复乘同一个矩阵，沿特征向量的非零分量每次乘以 λ：

```text
λ=3：[1,1] → [3,3] → [9,9]
λ=0.5：[2,0] → [1,0] → [0.5,0]
```

绝对值大于 1 时该分量增长，小于 1 时趋向零。完整非线性网络和梯度的行为不能只凭单个权重矩阵的特征值断言。

PCA 使用协方差矩阵的特征向量作为主方向，对应特征值是该方向的方差。保留较大特征值对应的方向，可以保留更多方差。

- 特征值 9 和 1：保留 9 对应方向，保留总方差的 90%。
- 特征值 2 和 8：应保留 8 对应方向，课堂回答正确。

“方差更大”是 PCA 的标准，不保证对具体预测目标一定更重要。课堂首次询问 PCA 时回答不清楚，通过狭长点云的例子理解。

## 11. NumPy 对应版本

```python
import numpy as np

A = np.array([[2, 1], [1, 2]], dtype=float)
values, vectors = np.linalg.eigh(A)
```

A 为实对称矩阵，适合使用 eigh。values 是特征值，vectors 的每一列是对应的单位特征向量，`vectors[:, i]` 与 `values[i]` 配对。特征向量的符号或长度可能与手算不同，应验证 `A @ v = λv`。本课仅阅读此版本，未实际运行 NumPy。
